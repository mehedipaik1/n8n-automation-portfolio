## Projects

### 1. Website Monitoring & Alert Automation

An n8n workflow that checks website availability, logs status information, and sends Telegram alerts when a website goes down.

**Key Features**
- Automated website availability checks
- HTTP status code monitoring
- Google Sheets logging
- Telegram alert integration
- Data Table-based website status tracking

**Tools & Technologies**
- n8n
- HTTP Request
- Google Sheets
- Telegram
- n8n Data Tables

**Workflow File:** [website-monitoring-public-safe.json](./website-monitoring-public-safe.json)

**Note:** This is a sanitized workflow template. Configure your own credentials, Google Sheet, Telegram chat, and Data Table after importing it into n8n.
